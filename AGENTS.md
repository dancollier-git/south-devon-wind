# Repository guidance

For a daily wingfoiling forecast/report requested in chat, read DAILY_REPORT.md
and use its live tide lookup procedure. Tide data is report context, not part of
the archived forecast collector. Do not claim that a repository instruction file
installs an automatic GPT task or a tide API. Preserve the hourly Prawle collector,
forecast snapshots and separate accuracy calculations. Owner gear recommendations
should learn from actual wing/foil session feedback, not an assumed bias correction.
